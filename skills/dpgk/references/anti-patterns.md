# 避けるパターン

「AIが作った動く図」にありがちな、理解を遅くする動きのカタログです。リンター（`scripts/dpgk_lint.ts`）で機械的に拾えるものには検査IDを付けています。

## 動きの問題

| パターン | なぜ悪いか | 代わりに | 検査ID |
|---|---|---|---|
| 常時回転・ふわふわ浮遊・脈動 | 意味を持たず視線を奪う | 動かさない | `W-FRANTIC`（周期1秒未満の無限ループ） |
| 全要素が同時に動く | どこを見ればよいか分からない | 主役を1つに絞る | `W-BUSY`（周期2秒未満の無限ループ3個以上） |
| 要素ごとにバラバラの周期で無限ループ | 2周目以降で順序が崩れる | 1本のタイムラインに揃える | `W-MIXED-PERIOD` |
| 最終フレームが最初と同じに見える | 止めると何も伝わらない | 番号を振り、到着した矢印を残す | - |
| パケットが止まった位置でラベルに重なる | 最終状態が読めない | 停車位置を文字の外に置く。`dpgk_snap.ts` で確認 | - |
| ループの終わりに静止がない | 最終状態を読む前に消える | 1.5秒以上の静止を入れる | - |
| 文字が出てすぐ消える | 読めない | 出てから1.5秒以上残す | - |
| `prefers-reduced-motion` 未対応 | 前庭障害のある読者を害する | `animation: none` で最終状態を表示 | `E-NO-REDUCED-MOTION` |
| 何も動かない | このスキルの出力として不十分 | ビート表から動きを付ける | `E-NO-ANIMATION` |

## 見た目の問題

| パターン | なぜ悪いか | 代わりに | 検査ID |
|---|---|---|---|
| グロー・ネオン・グラデーションの多用 | 情報がない装飾で、ラベルが読みにくくなる | 単色の面と線 | `W-DECOR`（0 0 Npx の影、feGaussianBlur） |
| 回り続ける枠・流れ続ける光沢や背景 | 説明と無関係に視線を奪い続ける | 動かさない | `W-DECOR`（rotate / 360deg / background-position の無限ループ） |
| 絵文字アイコン | 環境で見た目が変わり、意味が曖昧 | 図形とラベル | `W-EMOJI` |
| 12px未満の文字 | 縮小表示で読めない | 12px以上 | `W-SMALL-TEXT` |
| 色だけで区別 | 色覚多様性に対応できない | 形・ラベル・線種も変える | - |
| 背景色を持たない | ダークモードの埋め込み先で消える | SVG/HTML自身に背景を持たせる | - |

## 構造の問題

| パターン | なぜ悪いか | 代わりに | 検査ID |
|---|---|---|---|
| 外部CDN・Webフォント・外部画像 | オフライン・埋め込み先で壊れる | インラインにする | `E-EXTERNAL` |
| SVGに `<script>` | `<img>` 埋め込みで動かない | CSS / SMIL | `W-SVG-SCRIPT` |
| SVGに `viewBox` がない | 拡大縮小できない | `viewBox` を付ける | `E-NO-VIEWBOX` |
| `<title>` がない | スクリーンリーダーで内容が分からない | `<title>`（SVGは `<desc>` も） | `W-NO-TITLE` |
| ループで `animation-delay` を使う | 2周目以降に出番がずれる | `@keyframes` の％で出番を区切る | - |

## 内容の問題

| パターン | なぜ悪いか | 代わりに |
|---|---|---|
| 1枚に問いを詰め込む | 何の図か分からない | 問いを1つに絞り、図を分ける |
| 演出のために事実を曲げる（順序の入れ替え、存在しない矢印） | 誤解を生む | 単純化は省略にとどめ、出力時に明記 |
| 凡例がないと読めない記号 | 読む負担が増える | 図中にラベルを直接書く |
