dpgk

説明を、動く図解に。概念や仕組み、手順を意味のある動きで見せる SVG や HTML を、1 ファイルで作る Agent Skill です。

GitHub リポジトリ（umaidashi/dpgk）

動く例

JavaScript のイベントループHTML プレイヤー git rebase と mergeHTML プレイヤー Remotion の仕組みHTML プレイヤー 二分探索とリニアサーチHTML プレイヤー + スライダー DNS の名前解決README に貼れる SVG

操作

  • 開くと自動で再生が始まり、画面上辺のバーで全体の進み具合が分かります。
  • 図をタップすると一時停止し、もう一度タップすると再開します。長押ししている間だけ 2 倍速になります。
  • 押したまま上下にドラッグすると、0.1〜10 倍の範囲で速度が変わります。引くほど急に変わります。
  • キーボードでは、← → でステップ送り、Space で一時停止、< > で速度の切り替え、F で全画面になります。
  • スマホを縦に持つと、縦向きの配置に切り替わります。
