dpgk

説明を、動く図解に。概念・仕組み・手順を、意味のある動きで見せる SVG / HTML を 1 ファイルで作る Agent Skill です。

動く例

JavaScript のイベントループHTML プレイヤー git rebase と mergeHTML プレイヤー Remotion の仕組みHTML プレイヤー 二分探索とリニアサーチHTML プレイヤー + スライダー DNS の名前解決README に貼れる SVG

操作

  • 開くと自動再生。上辺のバーで全体の進み具合が分かる
  • 図をタップで一時停止 / 再開、長押ししている間だけ 2 倍速
  • 押したまま上下にドラッグで 0.1〜10 倍速（引くほど急に変わる）
  • キーボード: ← → ステップ送り、Space 一時停止、< > 速度、F 全画面
  • スマホを縦に持つと縦向きの配置に切り替わる

導入

npx skills add umaidashi/dpgk
